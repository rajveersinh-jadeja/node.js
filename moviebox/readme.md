# MovieBox

MovieBox is a simple movie management web application built with Node.js, Express, MongoDB, and EJS.

##video explanation 
https://drive.google.com/file/d/1dzvIthle4-VSqKqeimr4P0JlAguNY8sl/view?usp=drivesdk

## Features

* View movies
* View movie details
* Search movies
* Add movies
* Edit movies
* Delete movies
* Store movie data in MongoDB

## Technologies

* Node.js
* Express.js
* MongoDB
* Mongoose
* EJS
* HTML
* CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/rajveersinh-jadeja/node.js.git
```

Go to the project folder:

```bash
cd node.js/moviebox
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm run dev
```

The application will run on:

```text
http://localhost:3000
```
